02 · 拆开看 / HOW IT WORKS

它到底在解决什么

空包弹稿（ghost deck）是先只写标题、不填内容的骨架：每页一个行动标题，页与页之间用「所以呢 / 为什么」串起来。好处是返工成本极低——逻辑不通时改几行字，比改二十张做好的图便宜太多。

常用串法有两种：并列式（几个理由平行支撑一个结论）和递进式（S → C → Q → A 一路推到建议）。串的时候逐页问：「上一页的结论，是不是正好逼出下一页的问题？」答不上，说明中间缺了一页。

为什么管用

一上来做 PPT，会把力气花在配色和动画上，最后才发现逻辑接不上。空包弹稿只用一行行标题先把论证走通：逻辑不通时改一行字，比改二十页幻灯片便宜太多。

拆成三块逐块检查，缺哪块就补哪块
每页一行行动标题先只有字，没有图也没有美化。
检查接缝页与页之间要能用「所以呢 / 凭什么」接上。
逻辑通过再美化顺序反了，返工成本会翻几倍。

04 · 举个真例子 / THE COFFEE STAND

周末咖啡摊，摊开来算一遍

EXAMPLE · 示意算例

五页空壳：①「周六下午客流是工作日 2.4 倍」→ ②「但多开两小时的新增人工吃掉一半增量毛利」→ ③「隔壁靠先付款把队伍压到 3 人」→ ④「因此建议只在周六延两小时并前置付款」→ ⑤「下周六试一次，看队伍与投诉」。连读发现第 ② 页和第 ③ 页接不上：一个讲成本、一个讲排队，中间缺一句「排队导致的流失比人工更贵」。补上这一页再去算数，省下两天白做的图表。

一步一步推给你看用符号、句式或示意数字走一遍；涉及数字均为教学假设，不是调研数据
  1. ① 列标题现状 → 问题 → 判定线 → 试算结果 → 建议 → 下一步纯文字，先不画图
  2. ② 查接缝从「判定线」到「试算结果」凭什么？→ 补一页算式接不上的地方就是缺页
  3. ③ 再美化逻辑评审通过后才开始做图把最贵的工作放最后
05 · 常见翻车 / WATCH OUT

最容易摔的这三跤

01

别这样

一上来就做二十张精美图表，最后发现结论顺序不对，全部重排。

02

别这样

空壳里写的是「背景 / 分析 / 总结」这类话题式标题，连读什么也检验不了。

03

别这样

页与页之间没有「所以呢」，靠口头过渡补逻辑，一离开讲解人就散架。

02 · 拆开看 / HOW IT WORKS

它到底在解决什么

绝大多数图表需求能归进四类：比较（谁多谁少 → 条形/柱）、构成（各占多少 → 堆叠条 / 饼，类别少才用饼）、趋势（随时间怎么变 → 折线）、关系（两个变量有没有关联 → 散点）。先归类，再选图，比在图库里翻样式快得多。

两个常见误用：用饼图比大小（人眼比角度比长度难），以及用双 Y 轴硬凑出「相关」——那多半只是把两条线放到一张纸上，不是关系。

为什么管用

图不好读，多半不是画得丑，而是形状和问题不匹配：想比大小却用饼图，想看趋势却用堆叠柱。先问「这张图要回答什么」，再选形状。

拆成三块逐块检查，缺哪块就补哪块
先定问题比较 / 趋势 / 构成 / 关系，四选一。
按问题选形状条、线、堆叠或瀑布、散点或矩阵。
标清口径单位、时间窗、分母写在图上。
03 · 三步上手 / DO IT

今天下午就能做的三件事

01

把想说的那句话写成四类之一。

02

按类选图，类别多就横向条形，时间序列就折线。

03

检查：读者三秒内能不能说出结论，不能就换或拆。

什么时候用，什么时候别用
该用

画图之前，或一张图被反复追问「这说明了什么」时。

别用 / 换招

只有一两个数时，直接写字比画图清楚。

别和「一图一事 / 一图明一事」搞混

一图一事决定「这张图要说什么」；图表选型决定「用什么形状说」。

04 · 举个真例子 / THE COFFEE STAND

周末咖啡摊，摊开来算一遍

EXAMPLE · 示意算例

要说的是「周六下午人比工作日多」——这是比较，用两根横向条，一眼看完。若误做成饼图，得写成「周六占 71%、工作日占 29%」，读者还得在心里换算回「多多少」，白白绕一圈。要说「最近六周客流怎么变」，那是趋势，换折线。要问「排队时长和复购有没有关系」，才是散点。

一步一步推给你看用符号、句式或示意数字走一遍；涉及数字均为教学假设，不是调研数据
  1. ① 定问题各时段销量谁高？→ 比较问题决定形状
  2. ② 选形状条形图（按高低排序），不用饼图饼图适合构成，不适合比高低
  3. ③ 标口径单位：杯；时间窗：周六 10–18 点没有口径的图不可复算

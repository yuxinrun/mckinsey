02 · 拆开看 / HOW IT WORKS

它到底在解决什么

出自《麦肯锡季刊》同名文章（Chris Bradley、Martin Hirt、Sven Smit 等）。十测分几组：市场与优势（我们要在哪竞争、凭什么赢）、趋势与不确定性、以及决策偏误与承诺（是不是被沉没成本绑住了、有没有真的把资源挪走）。

它的价值在于把「战略评审」从口号会变成可回答的十道题。尤其那几道偏误题，专治「大家其实都不信，但没人先说」。十题里最弱的那道，通常就是该先补的地方。

为什么管用

战略文档通常写得很好看，问题在于没人敢追问。十测把「看起来对」拆成十个能被具体回答的问题，尤其是「在哪竞争、凭什么赢、不确定性怎么留余地」。

拆成三块逐块检查，缺哪块就补哪块
市场与优势能否跑赢市场、优势到底从哪来。
具体性细化到在哪竞争、是否领先趋势，而不是行业大词。
可执行有没有被偏误污染、有没有转化成行动。
03 · 三步上手 / DO IT

今天下午就能做的三件事

01

把十道题抄下来，逐题写一句具体回答。

02

标出答不上来或只能喊口号的那几题。

03

挑最弱的一题，补一个可查的事实或一个具体动作。

什么时候用，什么时候别用
该用

战略定稿前做体检，或一份计划全是形容词时。

别用 / 换招

还在找方向、连基本假设都没有时，先做事实收集再测。

别和「不确定性四层级」搞混

十测查「这份战略结不结实」，不确定性四层级查「未来到底有多不确定」。

04 · 举个真例子 / THE COFFEE STAND

周末咖啡摊，摊开来算一遍

EXAMPLE · 示意算例

摊主的「战略」是「做本片区最好的咖啡」。拿十测一戳：要在哪竞争？→ 答「所有人」，等于没答；凭什么赢？→ 「豆子好」，但隔壁也这么说；资源真的挪了吗？→ 上周还说要重视办公室预订，结果一分钟都没花。三题下来，战略被改小成：「服务周边三栋写字楼的午后时段，凭提前预订、不用排队赢，本周先跑通两家。」能被回答的才叫战略。

一步一步推给你看用符号、句式或示意数字走一遍；涉及数字均为教学假设，不是调研数据
  1. ① 逐问打分10 问各记 0 / 1 分先打完再讨论，别边打边辩护
  2. ② 找最弱「是否基于独有洞察」= 0 → 这一条最可能翻车最弱的一条决定整体可信度
  3. ③ 转动作补一次老客访谈，把 0 分那条变成有证据或明确承认做不到不补证就写进风险清单
05 · 常见翻车 / WATCH OUT

最容易摔的这三跤

01

别这样

把十测做成打勾表，全打「是」交差，等于没测。

02

别这样

只测市场与优势，跳过偏误和承诺那几题，最痛的地方没人碰。

03

别这样

测完不排序，十道题一起改，最后一道也没改透。
